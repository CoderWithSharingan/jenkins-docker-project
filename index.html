Docker CI/CD Deployment

This application is containerized with Docker, automatically built through Jenkins, and served efficiently using Nginx.

Deployment Pipeline

1

Source Code

Application files and configuration are managed in a version-control repository.

2

Jenkins Build

Jenkins reads the pipeline definition and automates the build and deployment workflow.

3

Docker Image

Docker packages this website and its Nginx configuration into a portable image.

4

Nginx Hosting

Nginx runs inside the container and serves this website to visitors.

Technology Stack

HTML5 Docker Jenkins Nginx CI/CD

Deployed using Docker, Jenkins CI/CD, and Nginx.
